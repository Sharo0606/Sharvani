# EduGenie: Google Gemini Powered Learning

EduGenie is a student-focused AI learning assistant. It provides an interactive interface for asking academic questions, getting explanations, summaries, study notes, and quiz questions.

## Project Structure
- `index.html` - main application page
- `src/style.css` - application styling
- `src/app.js` - application logic and demo AI response
- `src/gemini.js` - optional Google Gemini API integration template
- `docs/PROJECT_REPORT.md` - project documentation
- `docs/FEATURES.md` - feature list
- `docs/SETUP.md` - setup instructions

## Run
Open `index.html` in a browser. The project works in demo mode without an API key.

## Gemini API
For real Gemini responses, add your API key only in a secure backend environment. Do not publish API keys in client-side code.
